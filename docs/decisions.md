# Decisions

| Date | Decision | Reason |
| --- | --- | --- |
| 2026-11-07 | Slint `=1.18.1` instead of the plan's 1.17.x; workspace `rust-version = "1.92"` | 1.18.1 is the current stable patch (Sep 21); it requires Rust 1.92, above AGENTS.md's 1.85 floor. |
| 2026-11-07 | Software renderer by default; FemtoVG stays behind the `ui/femtovg` feature | Spike: FemtoVG costs ~43 MB more private working set for a modest CPU saving. Numbers in `measurements.md`. Confirm in M3 with the real UI. |
| 2026-11-07 | The librespot session logs in with Spotify's desktop client ID (`streaming` scope, redirect `127.0.0.1:8898/login`); Hush's own Client ID is used for the Web API only | A token from Hush's Client ID passes the access point, but clienttoken rejects Hush's ID (HTTP 400) and login5 rejects the stored credential it yields under the default client ID (`INVALID_CREDENTIALS`), so no track loads. The session login runs once; librespot then reuses its cached credentials. |
| 2026-11-07 | Session login reuses `auth`'s PKCE code instead of `librespot-oauth` | `librespot-oauth`'s async login blocks a tokio worker on a std `TcpListener` and builds its own `reqwest::Client`. |
| 2026-11-07 | `vergen` locked to 9.0.6 in `Cargo.lock` | `librespot-core` 0.8.0's build script fails with vergen 9.1 (incompatible `vergen-lib`). |
| 2026-11-07 | Volume uses librespot's `SoftMixer`; the player gets `NoOpVolume` and `EqSink` reads the mixer's `VolumeGetter`, instead of a custom `AtomicMixer` | `SoftMixer` already keeps the mapped volume in an atomic and Spirc drives it; a custom mixer would duplicate it. Volume still lands after the EQ. |
| 2026-11-07 | `EqSink` streams 44.1 kHz to cpal 0.18 and lets Windows resample, instead of a resampler crate | cpal 0.18 opens WASAPI shared-mode output with `AUTOCONVERTPCM` and `SRC_DEFAULT_QUALITY`, so the audio engine converts to the device rate (usually 48 kHz). cpal 0.16 did not, which would have needed `rubato`. |
| 2026-11-07 | The safety limiter is a static soft-knee curve (knee at −1 dBFS, `tanh` above it); normalisation keeps librespot's dynamic limiter | It only has to catch EQ boosts that pass full scale, so it needs no attack/release state and cannot pump. |
| 2026-11-07 | Dark title bar via winit's window theme (`with_theme(Dark)` in Slint's attributes hook) instead of calling `DwmSetWindowAttribute` | winit already applies the dark mode on Windows; no unsafe code or HWND lookup needed. |
| 2026-11-07 | Software renderer confirmed with the real M3 UI | 9–13 MB private working set and under 4% of one core with the progress bar animating; numbers in `measurements.md`. |
| 2026-11-07 | Design direction changed to art-led and immersive (icon rail, poster type, bottom control strip; no glows, no glass panels) | The owner's preference over the Apple Music–style and the translucent-glass versions. The software renderer has no blur or shadows and drops rounded corners on gradients, so the design relies on solid fills and, from M8, the art itself. |
| 2026-11-07 | The window background changes colour while minimized | After a restore, Slint's software renderer repaints only dirty regions into a buffer Windows has cleared, leaving stale or black areas while the progress bar animates. A background change marks the whole window dirty. |
| 2026-11-07 | Seek and volume commands update the view before librespot confirms them | The player's confirming event arrives tens of milliseconds later, long enough for the bar or slider to visibly jump back. |
| 2026-11-07 | The Web API sign-in runs before the Connect device starts, not alongside it | Both browser logins listen on `127.0.0.1:8898`. With a stored refresh token the sign-in is one token request, so the device starts a few hundred milliseconds later. |
| 2026-11-07 | The app reads `/me` (24 h TTL) at startup and logs the user's name | It is the gateway's only real caller until library sync, and it exercises tokens, the HTTP cache and the gateway end to end. A warm start costs 0 requests. |
| 2026-11-07 | A 401 calls `TokenProvider::refresh_rejected(token)`, which replaces `expire()` | Several requests rejected with the same token trigger one refresh between them, not one each. |
| 2026-11-07 | Only endpoints in the gateway's TTL table go into `http_cache`, keyed by full URL | It keeps the table to a fixed set of URLs. Library pages land in entity tables instead (M5). |
| 2026-11-07 | `QUOTA_EXCEEDED` is detected by searching the whole 429 body | Spotify does not document where `reason` sits in the error body. |
| 2026-11-07 | A quota 429 fails its request at once, and queued P2/P3 requests fail while the breaker is open | Callers fall back to cached data rather than wait up to an hour. P0/P1 resume after `Retry-After`. |
| 2026-11-07 | Retry jitter comes from a freshly keyed `std::hash::RandomState` instead of `rand` | Spreading retries needs no quality randomness; it saves a dependency. |
